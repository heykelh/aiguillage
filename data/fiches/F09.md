# Qualité des données : doublons ou données manquantes

## Symptômes
Doublons dans un rapport, données manquantes dans un tableau de bord Power BI, écarts entre deux exports, dataset incomplet.
## Diagnostic
1. Identifier la table et la date de chargement concernées.
2. Lancer les contrôles qualité (unicité, complétude, fraîcheur) sur la couche concernée.
## Actions
- Doublons : corriger la clé de dédoublonnage et recharger la partition.
- Données manquantes : vérifier le pipeline amont, voir fiche F08.
## Escalade
Équipe Data, puis propriétaire du dataset.
