# Réservation impossible ou panier bloqué sur le site de vente

## Symptômes
Le client ne peut pas finaliser sa réservation, le panier se vide, erreur à la validation de la commande, billets non émis.
## Diagnostic
1. Reproduire le parcours sur l'environnement de production avec un compte de test.
2. Consulter la supervision de l'API de réservation (taux d'erreur, temps de réponse).
3. Vérifier la disponibilité du système d'inventaire des places.
## Actions
- API de réservation en erreur : redémarrer les instances selon le runbook applicatif, informer le support client.
- Inventaire indisponible : déclencher la cellule incident Vente.
## Escalade
Astreinte Vente, puis cellule incident.
